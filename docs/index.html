lightpanda-static

fully staticpure-muslx86_64i386 / 32-bit

Fully static Lightpanda builds for x86_64 and the i386 (32-bit x86 / i686) port — zero glibc, no libc-loader needed at runtime. They run on any Linux regardless of distro: Alpine/musl, Debian/Ubuntu/glibc, distroless. A usable browser hand-built for the 32-bit world, plus the full build recipe.

Download the binaries

These are the GitHub Releases — statically linked musl, ELF, arch-per-binary:

AssetArchSize
lightpanda-1.1.0-dev-x86_64-muslx86_64~199 MiB
lightpanda-1.1.0-dev-i686-musli386 (32-bit)~169 MiB

Note: the 32-bit asset file is named i686 (its real ISA floor — V8 needs CMOV/MMX); "i386" is the human-facing label for 32-bit x86, as Debian uses it.

Install & verify

sudo install -m 0755 lightpanda-*-musl /usr/local/bin/lightpanda
lightpanda version                  # Lightpanda 1.1.0-dev
ldd /usr/local/bin/lightpanda       # "not a dynamic executable" (static)
lightpanda fetch --dump semantic_tree_text https://example.com

What's here

  • Full build recipe — see build/README.md.
  • musl_glibc_shim.c — a small glibc-symbol compat layer folded into the V8 archive so Lightpanda links pure-musl.
  • i386 port: the capability toolchain carries directly to an i386 Chromium if it's ever needed.
